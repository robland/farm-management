# OPEN_QUESTIONS.md

Points de clarification à revoir avec le porteur du projet **une fois le cahier des charges actuel implémenté**.

En attendant une réponse, chaque question est traitée avec un **choix par défaut**. Ce choix est appliqué dans le code et noté ici. Changer un choix doit se faire par une décision explicite, documentée dans `docs/adr/`.

Statuts : `OUVERTE` (choix par défaut appliqué) · `TRANCHÉE` (réponse humaine reçue).
